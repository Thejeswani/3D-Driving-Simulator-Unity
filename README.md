3D Driving Simulator using Unity

Project Overview

This project is a simple interactive 3D driving simulator developed using Unity and C#. The objective is to explore the fundamentals of 3D game development by creating a vehicle that can move and steer along a road while interacting with obstacles.

Features

- 3D road and environment setup
- Vehicle movement using keyboard controls
- Forward and backward movement
- Left and right steering
- Follow camera system
- Physics-based interactions using Rigidbody and Colliders
- Obstacles placed along the road
- Collision detection

Technologies Used

- Unity 6
- C#
- Unity Physics System
- Visual Studio / C# scripting

Controls

| Key | Action |
|---|---|
| Up Arrow | Move Forward |
| Down Arrow | Move Backward |
| Left Arrow | Turn Left |
| Right Arrow | Turn Right |

Concepts Learned

- Unity Editor and GameObjects
- Components and Transform
- C# variables and methods
- Vectors and object movement
- Keyboard input handling
- Rigidbody and Colliders
- Camera-follow scripting
- Physics and collision detection

How to Run

1. Clone or download this repository.
2. Open Unity Hub.
3. Select Add Project from Disk.
4. Select the downloaded project folder.
5. Open the project using the compatible Unity Editor version.
6. Open the main game scene and press Play.

Project Purpose

This project was developed as a learning experience to understand the fundamentals of interactive 3D game development using Unity and C#.
